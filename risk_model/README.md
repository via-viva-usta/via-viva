# risk_model/

Modelo predictivo georreferenciado: probabilidad de huecos no reportados por tramo de calle (OSM).
Regresión logística y bosque aleatorio con validación espacial (barrios completos fuera).
Salida: mapa de calor y ranking de tramos a revisar.

**Estado:** no iniciado (semana del 3 al 6 de noviembre).
