# firmware/nodo-sensores

Proyecto PlatformIO para la **ESP32-S3-DevKitC-1 N16R8** (16 MB flash, 8 MB PSRAM octal).
Lee ADXL345 por SPI (FIFO + interrupción), MPU-6050 y VL53L0X por I2C, GPS NEO-6M por UART,
registra en microSD y recibe etiquetas con un pulsador. Pines en la sección 5 de `CLAUDE.md`.

**Estado:** pendiente (Fase 2).
